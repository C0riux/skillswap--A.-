# skillswap--A.-
Title: Skill Swap Web App

Description: This is a project for a software development course. Skill Swap is a web app that enables students to discover and arrange paid meeting with tutors. Users can either take the role of student, tutor, or both; those who take the option of "both" may exchange their tutoring services directly for credits to be spent on tutoring services for themselves, hence the name "skill swap."

Technologies: HTML, CSS, JavaScript, SQL
